# API 类型 / API Types

HTTP 请求与响应、钱包认证错误类型放在此处。持久化实体仍由 `entity/` 管理。
This package holds HTTP request and response types and wallet authentication errors. Persistence records live in `entity/`.

`WalletAuthApi` 对应连接 Phantom、查询当前登录状态与进入仓库工作台的调用。
`WalletAuthApi` covers Phantom sign-in, the current session, and Warehouse Workbench access.
