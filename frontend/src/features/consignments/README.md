# 藏品寄存

`consignmentTypes.ts` 定义寄存和仓库工作台共用的单据、状态、分类和编号类型。 `api/` 提供创建寄存、查询本人列表与详情。仓库动作的 API 在 [仓库工作台功能目录](../warehouse/README.md)。

`consignmentTypes.ts` defines the record, status, category, and identifier types shared by the depositor and warehouse screens. The `api/` directory contains the create, depositor list, and detail calls. The warehouse actions live in the [warehouse feature](../warehouse/README.md).
