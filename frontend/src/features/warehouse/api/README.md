# 仓库接口

本目录提供仓库权限校验、寄存队列和详情查询，以及登记收货、验收、拒收和退件的请求方法。寄存单类型在 [寄存功能目录](../../consignments/README.md) 中共用，页面负责按服务端状态呈现操作。

This directory provides warehouse access checks, consignment queue and detail queries, and requests to receive, approve, reject, or return an item. The [consignment feature](../../consignments/README.md) supplies the shared record types. The page selects available actions from the backend state.
